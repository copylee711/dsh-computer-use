## 哪些信息会进入会话

模型可以获得当前屏幕截图，以及通过 UI Automation 读取的控件名称、值和窗口文字。截图作为当前 DSH 会话的图片附件发给你选用的模型，插件没有另设上传服务。

截图附件存放在 `~/.dsh/attachments`。DSH 校验历史消息引用的附件，插件会保留仍被会话引用的截图。删除会话后，失去引用的截图会在 DSH 启动后的定期任务中清理；也可在 **设置 → 电脑控制 → 截图缓存** 查看占用并清理。

## 应用授权与 Windows 限制

- 默认按应用授权。DSH 自身、常见密码管理器和用户设置的禁用应用受保护。识别到 DSH Web GUI 时，插件也会保护该浏览器窗口。
- 管理员窗口、UAC 弹窗和锁屏受 Windows 权限限制，需要用户直接处理。
- 插件的系统提示要求模型将密码、支付信息和验证码交给用户处理。

## 剪贴板与本地文件

- 用于输入文字的临时剪贴板内容不会进入 Windows 剪贴板历史或云剪贴板。写入后会尝试还原原内容；若用户期间复制了新内容，会保留用户的内容。
- 辅助程序源码随 npm 包发布。编译产物缓存在 `%LOCALAPPDATA%\dsh-computer-use\`，进程内功能使用 DSH 自带的 koffi 和 Windows 系统 DLL。
