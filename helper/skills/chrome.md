---
- 打开网址最快的方式：ctrl+l 聚焦地址栏，输入完整网址，Return。不要去点书签或一层层点链接；知道确切地址就直接输入（例如 GitHub 仓库的 PR 列表是 仓库地址/pulls）。
- 页面内容多时用 ctrl+f 页内查找定位，Return / shift+Return 跳到下一个 / 上一个，Escape 关闭查找条。
- 看长页面：Page Down / Page Up 翻页，End / Home 到底部 / 顶部；也可以 scroll。
- 用户的 Chrome 通常已经开着很多标签页：新任务用 ctrl+t 开新标签页，不要占用或关闭用户原有的标签页；自己开的标签页用完 ctrl+w 关掉。
- 登录、支付、验证码交给用户处理。
- 快捷键：ctrl+t 新标签页；ctrl+w 关闭标签页；ctrl+shift+t 恢复刚关闭的标签页；ctrl+Tab / ctrl+shift+Tab 下一个 / 上一个标签页；ctrl+1…8 切到第 N 个标签页；ctrl+l 地址栏；alt+Left / alt+Right 后退 / 前进；F5 或 ctrl+r 刷新，ctrl+shift+r 强制刷新；ctrl+f 页内查找；ctrl++ / ctrl+- / ctrl+0 放大 / 缩小 / 恢复缩放；ctrl+j 下载内容；ctrl+h 历史记录；ctrl+shift+n 无痕窗口；F12 开发者工具。
