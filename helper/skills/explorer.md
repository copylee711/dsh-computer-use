- 去某个文件夹：ctrl+l（或 alt+d）聚焦地址栏，输入完整路径，Return。不要一层层双击。
- 只是查看、复制、移动、重命名文件，用 shell 命令更快更准；只有用户想看到窗口里的结果时才操作资源管理器。
- 快捷键：win+e 打开新窗口；ctrl+l 地址栏；ctrl+e 或 ctrl+f 搜索框；alt+Up 上一级，alt+Left / alt+Right 后退 / 前进；ctrl+shift+n 新建文件夹；F2 重命名；Delete 删到回收站；ctrl+c / ctrl+x / ctrl+v 复制 / 剪切 / 粘贴；ctrl+a 全选；alt+Return 属性；F5 刷新；ctrl+t 新标签页，ctrl+w 关闭标签页。
