summary: 单元格录入、公式、另存为、快捷键
---
- 定位单元格最稳的方式：点左上角“名称框”（或按 ctrl+g），输入地址如 B3，Return。
- 录入：输入内容后 Return 到下一行，Tab 到右边一格；一行数据用 Tab 分隔、行末 Return，可以整块连续输入。F2 进入当前单元格编辑。
- 公式以 = 开头，如 =SUM(A1:A10)、=AVERAGE(B2:B9)；输入后 Return 确认，Escape 取消。
- 另存为：F12 → alt+n → ctrl+a → 输入完整路径（含 .xlsx）→ Return。
- 快捷键：ctrl+Home 回到 A1；ctrl+End 到已用区域末尾；ctrl+方向键 跳到数据边缘，加 shift 则选中；ctrl+a 选中当前数据区域；ctrl+space 选整列，shift+space 选整行；ctrl+c / ctrl+v / ctrl+x 复制 / 粘贴 / 剪切；ctrl+z / ctrl+y 撤销 / 重做；ctrl+d 向下填充，ctrl+r 向右填充；ctrl+1 设置单元格格式；ctrl+b 粗体；ctrl+shift+l 筛选开关；ctrl+t 转为表格；alt+= 自动求和；ctrl+; 输入当天日期；ctrl+Page Down / ctrl+Page Up 切换工作表；shift+F11 新建工作表；ctrl+f 查找，ctrl+h 替换；ctrl+s 保存；ctrl+w 关闭工作簿。
