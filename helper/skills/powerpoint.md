app: PowerPoint
match: PowerPoint, POWERPNT.EXE
summary: 建页、原生公式、动画与切换、插图、另存为、快捷键
---
- 启动后在开始页点“空白演示文稿”。ctrl+m 新建幻灯片（沿用当前版式）；正文框里 Tab / shift+Tab 升降大纲级别。
- 原生公式（不要把公式当普通文本打）：光标放在文本框里 → “插入”选项卡 → 最右侧“公式”（π 图标），出现“在此处键入公式”。用 type 输入线性格式，分子分母各自加括号，然后点“公式”选项卡“转换”组里的“专业”，整条公式一次排成原生样式。
  - 写法示例：`dy/dx=-(F_x (x,y))/(F_y (x,y))`、`(\partial F)/(\partial y)\ne 0`、`x^2+y^2=1`、`\sqrt(1-x^2)`、`\sum_(i=1)^n a_i`、`F\in C^1`、`\nabla F=(F_x,F_y)`、`\int_a^b f(x)dx`、`\lim_(x\to 0)`。希腊字母用 `\alpha` `\delta` 等，后面跟一个空格。
  - 不要输入 LaTeX 的 `\frac{}{}`：边打边被套用格式，会乱掉，“LaTeX 转换”按钮也救不回来。
  - 公式写完按 End 再 Return 回到普通文本的新段落；alt+= 在本机不起作用，走功能区。
- 动画：先选中对象。给整个正文框按段落加动画，要选中文本框本身（在文字里按 Escape，直到四周出现控制点），再到“动画”选项卡点效果（出现 / 淡化 / 飞入 / 浮入 / 擦除）；如果只是光标停在某一段，只有那一段会加上动画。加好后段落左侧出现序号 1、2、3。
- 页面切换：“切换”选项卡选一个效果（淡入/淡出、推入、平滑），再点“应用到全部”。
- 小写字母开头的段落会被自动改成大写（f → F）；写完用 ctrl+h 替换改回。
- 插图：“插入”→“图片”→“此设备”，菜单弹出后等约 1 秒再点；在对话框里 alt+n，输入图片完整路径，Return。过大的图会自动缩到铺满幻灯片；想要精确尺寸就先把图片文件做成目标大小。图片挡住文字时，选中图片，“图片格式”→“下移一层”。
- 另存为：F12 → alt+n → ctrl+a → 输入完整路径（含 .pptx）→ Return。
- 快捷键：ctrl+m 新幻灯片；ctrl+d 复制所选幻灯片或对象；ctrl+z / ctrl+y 撤销 / 重做；ctrl+b / ctrl+i / ctrl+u 粗体 / 斜体 / 下划线；ctrl+e / ctrl+l / ctrl+r 居中 / 左对齐 / 右对齐；ctrl+] / ctrl+[ 增大 / 减小字号；ctrl+a 全选当前框内文字或当前页对象；ctrl+g 组合；Page Down / Page Up 下一页 / 上一页；ctrl+Home / ctrl+End 第一页 / 最后一页（焦点在缩略图栏或幻灯片上、不在文本框里时）；F5 从头放映，shift+F5 从当前页放映，Escape 退出放映；ctrl+f 查找，ctrl+h 替换；ctrl+s 保存；ctrl+w 关闭当前演示文稿。
