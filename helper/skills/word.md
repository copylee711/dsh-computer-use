---
app: Word
match: Word, winword.exe
summary: 新建文档、打字排版、另存为
---
- 启动后停在开始页：点“空白文档”（或直接按 Return）进入文档，窗口会换成“文档1 - Word”。
- 保存：按 F12 直接打开经典“另存为”对话框，alt+n 聚焦文件名框，ctrl+a，输入完整路径（如 C:\Users\<用户>\Desktop\标题.docx），Return。不要点左侧文件夹导航，也不要三击文件名框（会只选中一部分，文件名被拼接）。
- 打字：以“一、”“1.”开头的段落按 Return 后会触发自动编号和缩进；想保留原样，回车后立刻 ctrl+z 一次撤销自动套用，或写完后 ctrl+a 再 ctrl+q 清除段落格式。
- 标题格式：ctrl+Home 到开头，shift+End 选中该行，ctrl+b 加粗，ctrl+] 逐级放大字号，ctrl+e 居中。不要去点功能区的字号框再打字，容易把选中的标题文字替换掉。
- 查找用 ctrl+f（左侧导航窗格），用完按 Escape 关闭。
- 快捷键：ctrl+n 新建；ctrl+s 保存；F12 另存为；ctrl+z / ctrl+y 撤销 / 重做；ctrl+b / ctrl+i / ctrl+u 粗体 / 斜体 / 下划线；ctrl+e / ctrl+l / ctrl+r / ctrl+j 居中 / 左对齐 / 右对齐 / 两端对齐；ctrl+] / ctrl+[ 增大 / 减小字号；ctrl+alt+1 / 2 / 3 标题 1 / 2 / 3，ctrl+shift+n 正文样式；ctrl+Return 分页；ctrl+Home / ctrl+End 文首 / 文末；shift+End 选到行尾，ctrl+shift+Down 选到段尾，ctrl+a 全选；ctrl+f 查找，ctrl+h 替换；ctrl+q 清除段落格式，ctrl+space 清除字符格式；ctrl+w 关闭文档。
- 原生公式：“插入”→“公式”，输入线性格式（如 `dy/dx=-(F_x)/(F_y)`、`x^2`、`\sqrt(x)`、`\sum_(i=1)^n a_i`），再点“公式”选项卡里的“专业”排版。
