# 设置参考

[返回功能介绍](../README.md) · [安装与排障](getting-started.md) · [数据与权限](privacy.md)

打开 **设置 → 电脑控制**。保存后，设置在下一步操作中生效。页面也会显示分辨率、缩放和发给模型的截图尺寸。

## 授权与显示

| 设置 | 默认 | 说明 |
| --- | --- | --- |
| 授权方式 | 按应用授权 | 可切换为全部允许。 |
| 禁止操控的应用 | 空 | 填应用名或 exe，如 `alipay`。常见密码管理器另有内置禁用规则。 |
| 光晕与提示条 | 开 | 操作期间显示橙色光晕与状态。 |
| 提示条名称 | DeepSeek Harness | 自定义覆盖层的显示名称。 |
| 操控期间 DSH 窗口 | 迷你进度卡片 | 可选迷你卡片、悬浮卡片、最小化或保持不变。悬浮卡片支持鼠标穿透，鼠标停留时会提高不透明度。 |
| 卡片透明度 | 80% | 调整卡片背景。 |
| 强调色 | 陶土橙 | 调整插件设置页按钮与开关的颜色。 |

## 输入与截图

| 设置 | 默认 | 说明 |
| --- | --- | --- |
| 操作后自动截图 | 开 | 操作后待画面稳定再回传截图，重复画面可跳过。 |
| 等待稳定 | 400 ms | 操作后等待画面稳定的设置。 |
| 截图最长边 / 总像素 / JPEG 质量 | 1366 / 1.15 MP / 70 | 分辨率越高，细节越清晰，图片也越大。 |
| 文字输入方式 | 流式 | 长文本逐段粘贴，代码块保持完整。也可选逐字输入或一次粘贴。 |
| 检测到你在操作时暂停 | 开 | 打字时暂停，切换窗口后重新查看。 |
| 键盘静止多久后恢复 | 1500 ms | 停止物理键盘输入后自动恢复的等待时间。 |
| 操作时不深度思考（Beta） | 关 | 操控时尝试降低兼容模型的思考强度。参数不合法时可能重试一步。 |
| 进程内截图与输入 | 开 | 优先用 DSH 自带的 koffi 处理截图、窗口查询及浮层未显示时的输入。关闭后由辅助程序接管。 |

## Web GUI 地址

插件会从当前 DSH Web 服务的监听端口识别本机地址。通过反代或自定义域名访问时，在插件的 Loader 配置项 `copylee-computer-use` 的 `config` 下设置实际访问地址。

```yaml
harnessUrl: https://harness.example.com
```

识别范围以 URL 的协议、主机和端口为准。开始操作时，保持 DSH Web 标签处于前台，以便任务结束后返回该窗口并尝试选回原标签。
